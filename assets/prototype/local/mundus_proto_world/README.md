# Mundus Prototype World Pack

Local placeholder sprites for early `Mundus` world-map work.

Status: prototype-only, first-party placeholder art

## Purpose

This pack fills the gap between raw gameplay logic and a future real art
direction. The assets are intentionally simple and readable at small sizes.

## Included

- `ocean.svg`
- `coast.svg`
- `river.svg`
- `plains.svg`
- `forest.svg`
- `hills.svg`
- `mountain.svg`
- `city.svg`
- `capital.svg`
- `mine.svg`

## Notes

- These files are local project placeholders, not third-party imports.
- Prefer using stable local filenames from this directory in any asset lookup
  layer so they can be replaced later without touching game logic.
